Notes & blockers you should be aware of
- Many runtime problems are caused by behavioral differences, not missing files. Copying files may not fix bugs if the emulator depends on platform-native binaries (FFmpeg, Vulkan/Metal drivers, MoltenVK on macOS) or generated code from source generators.
- Source generators must run during build to produce some code; if CI/build environments strip generator outputs you may need the generated files checked-in or adjust the build.
- Large portions of the codebase rely on native interop and platform-specific behavior — I will document these and add guidance for installing native dependencies.
